# sergiowero.github.io

Página de presentación / CV de Sergio de Jesús Sánchez Robles.

- `index.html` — el CV publicado (diseño "Dark Terminal", hoja A4, HTML autocontenido con modo claro/oscuro).
- `Backups/` — las 9 variantes de diseño que se evaluaron (`Backups/index.html` es el selector con previews).
- `favicons/` — las 6 opciones de favicon; la elegida (`3-braces`) está en la raíz como `favicon.svg`, `favicon.ico` y `apple-touch-icon.png`.
- `tools/gen.py` — genera las variantes v2–v4 y v6–v9 desde datos compartidos y escribe la v3 también en `index.html` (`python3 tools/gen.py`). v1 y v5 están escritas a mano.
